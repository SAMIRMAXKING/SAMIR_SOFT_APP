# Furniture Store Web App

This is a simple static website demonstrating a furniture store. It includes several pages:

- `index.html` – Landing page with hero banner, highlights, testimonials, and newsletter form.
- `shop.html` – Product listing with basic filtering.
- `product.html` – Product detail page (opened with `?id=` query parameter).
- `cart.html` – View and manage items in the cart.
- `checkout.html` – Checkout form.
- `login.html` / `signup.html` – Basic sign-in and sign-up pages.

The application uses vanilla HTML, CSS, and JavaScript with localStorage to store cart contents and demo user accounts.

## How to Run
Open `index.html` in a browser. No build steps are required.

This project is a minimal prototype and does not include a real backend or secure authentication. It is meant for demonstration only.
